**주요 대기질 데이터 제공처**:

1. **한국환경공단_에어코리아_대기오염정보** (OpenAPI)
   - **데이터명**: 한국환경공단_에어코리아_대기오염정보
   - **기관**: 한국환경공단
   - **타입**: REST API
   - **형식**: JSON, XML
   - **제공 링크**: https://www.data.go.kr/data/15073861/openapi.do
   - **기능**: 측정소별 대기오염정보, 기간별/시도별 대기오염 정보, 통합대기환경지수(CAI) 조회, 미세먼지/오존 예보 등 제공
   - **라이선스**: 무료 (제3자 권리 포함 - 출처표시, 변경금지)

이 외에도 에어코리아에서 제공하는 다양한 API와 파일 형식의 데이터가 있으며, 그 중에는:
- 고농도 초미세먼지 예보 정보
- 오존/황사 발생 정보
- 통합대기환경지수(CAI) 조회 서비스
- 측정소별 실시간 측정정보 조회
- 최종확정 측정자료 (XLSX 파일)

등이 포함되어 있습니다.
