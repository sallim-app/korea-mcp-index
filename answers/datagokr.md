### 답변

공공데이터포털의 대기질 데이터는 **한국환경공단의 에어코리아(에어코리아) 오픈API**로 제공됩니다. 

**주요 대기질 데이터 API:**

1. **에어코리아 대기오염정보 (ID: 15073861)** — 가장 광범위
   - 측정소별 실시간 측정정보(SO₂, CO, O₃, NO₂, PM10, PM2.5 등)
   - 대기질 예보통보(미세먼지, 오존 등)
   - 통합대기환경지수(CAI) 나쁨 이상 측정소 현황
   - 시도별, 측정소별 실시간 측정정보

2. **에어코리아 대기오염통계 현황 (ID: 15073855)**
   - 기간별(주간/월간) 통계 정보
   - 지역별 평균정보

3. **에어코리아 측정소정보 (ID: 15073877)**
   - 측정소 위치, 목록 조회
   - TM 좌표 기반 근접 측정소 검색

4. **통합대기환경지수(CAI) 조회 (ID: 15140253)**
   - 각 측정소별 통합대기환경지수 지수

**사용 방법:**
- 공공데이터포털에서 해당 데이터셋 **활용신청** 필수
- 자동승인 또는 심의승인 후 **serviceKey** 발급
- 발급받은 serviceKey로 제공된 API URL에 호출
- 반환 형식: XML 또는 JSON 선택 가능
