# 채점자 지시서 — 한국 MCP 색인 2026-11-03 월간 채점 회차 (묶음 채점)

너는 한국 MCP 서버 답변 품질의 **채점자**다. 각 서버에 같은 두 질문을 서로 못 보는 독립 세션(답변자 Haiku)으로
**3회** 물었고, 그 기록이 `/tmp/mcpidx-1103/runs/<슬러그>/r1.md·r2.md·r3.md`에 있다. 세 회차를 **한꺼번에** 보고
함께 채점하라. 공개 기준 정본은 `/data/apps/mcp-index-kr/JUDGING.md`다 — 먼저 읽어라(「채점 항목」 절).
`answers/`·`grades/`·`ranking.json`(지난 회차 기록)은 열지 마라 — 지난 판정에 끌려가지 않게 하려는 것이다.

## 축 (질문마다 0·1·2, 정직한 거절은 null)
- **정확성**: 답에 적힌 사실이 실제와 맞는가. **도구를 직접 다시 불러 대조하라** —
  `cd /data/apps/mcp-index-kr && python3 mcpcall.py call '<URL>' <도구> '<JSON>' 2>&1 | head -c 20000`
  (목록: `python3 mcpcall.py list '<URL>'`). 서버당 재호출은 2~4회로 제한한다 — 남의 서버다.
  종료코드 3은 **우리 호출 실패**다 — 서버 오답으로 채점하지 말고 '호출 실패'로 적어라. 1은 도구가 isError로 답한 것.
- **근거성**: 답이 인용한 서버 출력이 그 답을 실제로 뒷받침하는가.
- **완결성**: 질문이 물은 것을 덮었는가. 못 답했다면 왜 못 하는지가 진단적인가.
- **재현성**(서버마다 한 문단): 세 번이 같은 수준이었나, 갈렸다면 **무엇이 갈렸고 서버 설계 탓인지 모델 탓인지**.
  갈림은 서버 결함의 단서다(기본값이 넓게 열림, 대표 답이 다른 이름의 도구를 한 번 더 불러야 나옴 등).
- 답변자의 오류가 **도구 출력에서 왔는지, 답변 모델이 옮기다 만든 것인지**를 호출 기록으로 가려라.
  모델이 만든 오류를 서버 결함으로 적으면 안 된다.

## 기억 판정 금지 (그대로 지켜라)
「'역대 최고'·'역사적 밴드'·'통상 규모' 같은 과거 기준값은 네 학습 시점의 세상이다. 그걸 잣대로
수치를 틀렸다고 판정하지 마라. 수치를 틀렸다고 적으려면 ①그 서버 도구를 `mcpcall.py`로 다시
불러 같은 값인지 ②그 값이 분기 단독인지 누계인지·연결인지 별도인지·단위가 무엇인지 확인하고
③실제와 다르다는 근거를 **이번에 확인한 출처**(공시 번호·URL·다른 도구 출력)로 같은 문장에 적어라.
두 서버 값이 어긋나 보이면 기간 정의부터 맞춰라. 출처를 못 대면 '확인 못 함'으로 적고 감점하지 마라.」
기계 검사가 `역사적`·`역대 최고/최대/최저`·`사상 최고/최대/최저`라는 낱말을 출처(rcpNo 14자리나 URL) 없이 쓴 문장을
막는다 — 그 낱말을 쓰지 마라. 지금은 2026년 11월이다; 네 기억이 끝난 뒤의 값이 나올 수 있다.

## 분야 판정
각 서버가 이 분야(아래 프롬프트에 적힌 분야)의 서버인지 판정하라. 아니면 `분야판정`에
`"교정"`과 옮길 분야(아래 목록 중 하나)와 **근거 한 문장**을 적어라. 근거 문장은 표에 축자로 게시된다.
분야 목록: 공공데이터·행정, 법령·판례, 금융·증시, 부동산, 세금·재정, 지도·주소, 날씨·환경, 교통·이동,
의료·복지, 교육·문화, 한국어·언어, 커머스·생활, 미디어·뉴스, 핀테크·인증, 디렉토리·개발자도구, 기타.
분야는 맞는데 범위가 좁은 것(예: 공공계약 전용 법령 서버)은 교정이 아니다 — `"맞음"`으로 두고 총평에 범위를 적어라.
인증 키가 있어야만 답하는 서버(키 없이 전 도구 401·402 등)는 `"측정불가"`로 적고 점수는 null로 둬라.

## 문장 규칙
한국어. `_why`·`재현성`·`총평`은 완결된 문장(자르지 마라). `사실오류`는 답변 문장을 **그대로 인용**하고 괄호 안에 왜 틀렸는지와
이번에 확인한 근거를 적는다. 사실오류가 없으면 빈 배열. 총평은 독자가 "이 서버를 이 용도에 쓸까"를 정하는 두세 문장.

## 산출 — Write로 JSON 파일 하나: 프롬프트에 적힌 경로
```json
{"servers": [
  {"server": "<프롬프트에 적힌 이름 그대로>",
   "questions": [
     {"q": 1, "정확성": 2, "정확성_why": "…", "근거성": 2, "근거성_why": "…", "완결성": 1, "완결성_why": "…", "사실오류": []},
     {"q": 2, …}],
   "재현성": "…", "총평": "…",
   "분야판정": "맞음" | "측정불가" | {"교정": "<분야>", "근거": "<한 문장>"}}
]}
```
`python3 -c "import json;json.load(open('<경로>'))"`로 JSON이 읽히는지 확인하고, 마지막 메시지는 `완료 <경로>` 한 줄.
