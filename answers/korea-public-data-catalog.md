# obundh/korea-public-data-catalog-mcp

## 질문 1: 서울시 인구가 최근 몇 년간 어떻게 변했어?

### 호출한 도구
| 순서 | 도구 | 인자 | 결과 |
|---|---|---|---|
| 1 | `recommend_data_combination` | `goal="서울시 인구 변화 추이 분석"` | 경상북도 포항시 월별 인구 변화 API 추천 (ID: 15139537) |
| 2 | `get_inventory_coverage_status` | 없음 | 카탈로그 메타데이터 96,056건 확인, 실제 값 미포함 |

### 답변

**이 서버로는 인구 값을 직접 얻을 수 없습니다.** 이 MCP는 공공데이터포털의 **카탈로그 메타데이터만 제공**하며, 실제 데이터 값은 포함하지 않습니다.

다만, 카탈로그 조회 결과 서울시 인구 데이터가 공공데이터포털에 존재할 가능성이 높습니다:
- **경상북도 포항시**: 월별 인구 변화 추이 API가 공공데이터포털에 등록되어 있습니다 (https://www.data.go.kr/data/15139537/openapi.do)
- 유사한 구조로 **서울시도 월별/연간 인구 통계 데이터**를 공개하고 있을 가능성이 높습니다

**실제 서울시 인구 데이터를 얻으려면:**
1. https://www.data.go.kr/ (공공데이터포털)에 접속
2. "서울시 인구" 또는 "인구통계"로 검색
3. 서울시청 또는 통계청이 제공하는 API/CSV 파일 확인
4. 공식 페이지에서 이용 조건 및 최신 데이터 확인

### 근거로 쓴 응답 발췌

```json
{
  "title": "경상북도 포항시_월별 인구 변화 추이",
  "classification": "공공행정 - 국가통계",
  "access_type": "API",
  "official_url": "https://www.data.go.kr/data/15139537/openapi.do",
  "formats": ["JSON"],
  "recommendation_reason": "요구 키워드와 명칭·기관·분류 메타데이터가 일치하는 라우팅 후보입니다"
}
```

## 질문 2: 공공데이터포털에서 대기질 데이터를 어디서 받을 수 있어?

### 호출한 도구
| 순서 | 도구 | 인자 | 결과 |
|---|---|---|---|
| 1 | `recommend_data_combination` | `goal="공기질 대기오염 데이터 수집"` | 충청북도 대기환경 API + 전국 대기오염배출시설 표준데이터 추천 |
| 2 | `get_inventory_coverage_status` | 없음 | 환경기상 분류 대기 카테고리 데이터셋 확인 |

### 답변

**대기질 데이터는 공공데이터포털에서 여러 경로로 제공됩니다.**

1. **API 방식** (실시간/근실시간 조회):
   - 충청북도 환경분야정보 - 대기환경 이동측정 데이터
     - URL: https://www.data.go.kr/data/15078994/openapi.do
     - 형식: JSON API
     - 키워드: 대기오염, 대기질모니터링, 대기측정

2. **표준데이터** (정구조화 데이터):
   - 전국 대기오염배출시설 설치사업장 표준데이터
     - URL: https://www.data.go.kr/data/15155660/standard.do
     - 제공처: 공공데이터활용지원센터

3. **지역별 데이터**:
   - 각 시·도 환경청/보건환경연구원에서 제공하는 대기질 데이터가 포털에 등록
   - 전북특별자치도 익산시 등 여러 지역의 대기환경 측정 데이터 있음

**데이터 이용 절차:**
1. 공공데이터포털(https://www.data.go.kr)의 "환경기상 - 대기" 카테고리 확인
2. 각 데이터셋의 공식 페이지에서 실제 스키마·갱신주기·현재 이용조건 재확인
3. API의 경우 인증키 발급 후 사용 (일반적으로 포털에서 무료 제공)

## 이 서버를 쓰면서 느낀 점

이 MCP는 **카탈로그 라우팅 서비스**로, 실제 데이터 값을 반환하지 않고 데이터가 어디에 있는지 안내합니다. 따라서 "값이 뭔가"는 답할 수 없지만 "이런 데이터가 있나"는 빠르게 확인할 수 있습니다. 사용자가 원하는 데이터의 존재 여부를 파악한 후 공공데이터포털 공식 페이지에서 직접 접근해야 실제 데이터를 얻을 수 있으며, 이때 최신 이용조건을 반드시 확인해야 합니다.
