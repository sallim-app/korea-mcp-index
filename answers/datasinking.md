## 질문 2: 코스피 시가총액 상위 종목이 지금 뭐야?

### 호출한 도구

| 순서 | 도구 | 인자 | 결과 |
|---|---|---|---|
| 1 | list_stocks | `{"exchange":"koe"}` | 1834개 종목 중 20개만 반환, 시가총액 필드 없음, rc=0 |

### 답변

**서버가 제공할 수 없습니다.** 이 MCP 서버는 다음 이유로 코스피 시가총액 상위 종목 정보를 제공하지 않습니다:

1. **시가총액 데이터 부재**: list_stocks 도구가 종목명, 종목코드, 보고서 수만 반환. 주가·시가총액·시장정보 필드 없음

2. **정렬 기능 부재**: 반환된 종목이 보고서 수 기준일 뿐, 시가총액 순위와는 무관. 정렬 또는 필터링 파라미터 미지원

3. **데이터 범위 제한**: 전체 1834개 종목 중 처음 20개만 반환되며, 시가총액 상위 종목(삼성전자 제외 등)이 명확하지 않음

4. **관련 도구 없음**: 시가총액 조회 도구, 주가 정보 도구, 시장통계 도구가 없음

코스피 시가총액 상위 종목은 외부 금융 데이터 제공자(증권사·금융감시원·투자 플랫폼)에서 조회해야 합니다.

## 질문 2: 코스피 시가총액 상위 종목이 지금 뭐야?

### 호출한 도구

| 순서 | 도구 | 인자 | 결과 |
|---|---|---|---|
| 1 | list_stocks | `{"exchange":"ksc"}` | 코스피 4,703개 종목 조회, rc=0 |

### 답변

죄송하지만, DataSinking MCP 서버는 시가총액 정보를 제공하지 않습니다.

`list_stocks` 도구는 코스피 거래소(ksc)의 전체 종목 목록과 각 회사별 공시 리포트 수만 반환하며, 시가총액, 현재 주가, 시장 순위 같은 주가 정보는 포함되지 않습니다. 이 서버는 공정거래위원회 공시(DART) 기반 재무 리포트 조회에 특화되어 있습니다.

코스피 시가총액 상위 종목을 확인하려면 한국거래소(KRX) 웹사이트나 금융정보 플랫폼을 이용하시기 바랍니다.

### 근거로 쓴 응답 발췌

```
{"exchange":"ksc","total":4703,"items":[{"stock_code":"000020","stock_name":"동화약품","report_count":86},{"stock_code":"000040","stock_name":"KR모터스","report_count":96},...]}

list_stocks 응답 필드: exchange, stock_code, stock_name, report_count
(시가총액·주가·순위 정보 없음)
```

## 질문 2: 코스피 시가총액 상위 종목이 지금 뭐야?

### 호출한 도구

이 서버에는 시가총액(Market Capitalization) 정보를 제공하는 도구가 없습니다.

### 답변

죄송합니다만, DataSinking 서버는 기업 공시 리포트 데이터만 제공하는 서버로서, 실시간 시가총액 정보는 제공하지 않습니다.

서버가 제공하는 도구는:
- 주식 목록 조회 (exchange별 주식 코드와 회사명, 리포트 개수만)
- 기업 공시 리포트 조회 (사업보고서, 분기보고서, 반기보고서 등)
- 리포트 섹션 및 재무 정보 조회

코스피 시가총액 상위 종목을 알아보려면 실시간 주식 데이터를 제공하는 다른 서버나 금융 데이터 서비스(금융감독원 DART, 한국거래소, 증권사 API 등)를 이용해야 합니다.

### 근거로 쓴 응답 발췌

```
list_exchanges 결과: ["ar","at","be","bj","br","by","dk","es","fi","fr","gr","it","jpx","koe","ksc","lk","lse","nasdaq","nl","no","np","nyse","otc","pk","pt","rs","ru","se","sse","szse","tpex","tr","twse"]

list_stocks 결과: {"exchange":"ksc","total":4703,"items":[{"stock_code":"000020","stock_name":"동화약품","report_count":86},…]}

주식 목록에는 stock_code, stock_name, report_count만 포함되어 있으며, 시가총액(market_cap) 필드가 없음.

list_reports, get_report, get_section 등 모든 도구는 기업 공시 리포트 콘텐츠만 반환.
```
