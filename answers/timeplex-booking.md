# ai.timeplex/booking

## 질문 1: 요즘 많이 팔리는 상품이 뭐야?

### 호출한 도구
| 순서 | 도구 | 인자 | 결과 |
|---|---|---|---|
| 1 | search_shops | {} | Spa Slick(hair) 1개 가게 발견 |
| 2 | get_shop_services | slug=spaslick | 여성/남성 오일케어 서비스 6가지 |

### 답변
이 서버는 Timeplex 예약 서비스의 가게와 서비스 목록만 제공하며, **판매량, 인기도, 매출 순위 정보는 없습니다.** 현재 등록된 가게는 Spa Slick(헤어) 한 곳뿐이고, 서비스별 예약 현황이나 판매 통계 데이터를 조회할 수 없습니다.

### 근거로 쓴 응답 발췌
```json
{
  "shops": [{"slug": "spaslick", "name": "Spa Slick", "business_type": "hair"}],
  "count": 1,
  "available_service_types": ["hair"]
}
```

## 질문 2: 이 서비스로 예약할 수 있는 게 뭐가 있어?

### 호출한 도구
| 순서 | 도구 | 인자 | 결과 |
|---|---|---|---|
| 1 | search_shops | {} | 1개 가게(Spa Slick) |
| 2 | get_shop_services | slug=spaslick | 6가지 서비스 조회 |

### 답변
Timeplex 서비스로 예약 가능한 상품은 다음과 같습니다:

**Spa Slick (서울 은평구)**
- 여성용:
  - VIP 호호바오일케어 (100분) - 160,000원
  - 디톡스 오일트리트먼트 (90분) - 130,000원
  - 베이식케어 (60분) - 100,000원

- 남성용:
  - VIP 호호바오일케어 (100분) - 160,000원
  - 디톡스 오일트리트먼트 (90분) - 130,000원
  - 베이식케어 (60분) - 100,000원

### 근거로 쓴 응답 발췌
```json
{
  "services": [
    {"name": "[女性] VIP ホホバオイルケア（100分）", "price": 160000, "duration_min": 100},
    {"name": "[女性]デトックス オイルトリートメント（90分）", "price": 130000, "duration_min": 90},
    {"name": "[女性]ベーシックケア（60分）", "price": 100000, "duration_min": 60}
  ]
}
```

---

## 이 서버를 쓰면서 느낀 점
Timeplex는 한국 뷰티·웰니스 가게의 **예약 중개 플랫폼**이며, 등록된 가게가 매우 제한적입니다(현재 헤어숍 1개만). 서비스 메뉴와 예약 가능 여부는 명확하지만, 업계 통계나 인기 상품 트렌드 같은 시장 데이터는 제공하지 않습니다.
