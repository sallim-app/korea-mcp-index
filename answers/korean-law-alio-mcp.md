# scvcoder/korean-law-alio-mcp

## 질문 1: 국가계약법상 수의계약을 할 수 있는 경우가 뭐야? 근거 조문도 알려줘.

### 호출한 도구
| 순서 | 도구 | 인자 | 결과 |
|---|---|---|---|
| 1 | search_law | {"query":"국가계약법","display":20} | 에러: API 키가 필요 (법제처 Open API) |
| 2 | search_ai_law | {"query":"국가계약법 수의계약","search":"0","display":10} | 에러: API 키가 필요 (법제처 Open API) |
| 3 | chain_full_research | {"query":"국가계약법 수의계약"} | 에러: 모든 서브 호출 실패 (AI 법령검색, 판례, 해석례 전부 API 키 문제) |
| 4 | search_legal_terms | {"query":"수의계약","display":10} | 에러: API 키가 필요 (법제처 Open API) |

### 답변
이 서버로는 답할 수 없다.

**이유**: 이 MCP 서버의 모든 법령 검색 기능이 법제처 Open API(law.go.kr)에 의존하는데, 클라이언트 측에서 API 키 인증이 제대로 이루어지지 않고 있다. 서버가 `LAW_API_KEY`를 받지 못하고 있으며, 이로 인해 다음 도구들이 모두 동일한 `API 키가 필요합니다` 오류를 반환한다:
- search_law (법령 키워드 검색)
- search_ai_law (자연어 의미 검색)  
- search_legal_terms (법령용어 검색)
- 이들을 사용하는 체인 도구들(chain_full_research, chain_action_basis 등)

서버의 다른 기능(ALIO 공공기관 규정 검색)은 정상 작동하지만, 국가계약법 같은 법령을 담고 있지 않다.

### 근거로 쓴 응답 발췌
```
❌ [EXTERNAL_API_ERROR] API 키가 필요합니다. 법제처(https://open.law.go.kr/LSO/openApi/guideResult.do)에서 발급받으세요.
```

## 이 서버를 쓰면서 느낀 점

**도구 선택은 비교적 직관적이었으나, 인증 장벽이 절대적이다.**

약 125개 도구 중 필요한 것(`search_law`, `search_ai_law`, `chain_full_research`)을 비교적 쉽게 찾을 수 있었다. 도구 이름과 설명이 명확하기 때문이다(예: "[법령검색] 법령명 키워드검색 → lawId, mst 획득"). 

그러나 **법제처 Open API 키 인증이 클라이언트-서버 간에 제대로 전달되지 않고 있어서**, 이 서버의 핵심 기능(법령 조회)을 쓸 수 없다. `/data/secrets/lawgo-oc.env`에 키가 보관되어 있고 서버 IP도 사전 등록되어 있는데, MCP 호출 경로에서 인증이 누락되는 문제로 보인다. 이는 MCP 프로토콜 레벨의 인증 메커니즘(Bearer 토큰 헤더, 환경변수 주입, 경로 파라미터 등)과 서버의 인증 기대 방식 간의 불일치에서 비롯된 것 같다. 인증만 해결되면 이 서버는 매우 유용할 것으로 보인다.
